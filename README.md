# 奶油猫桌面宠物（Windows）

这是一个独立的 Windows 桌面宠物原型。猫咪会在桌面上缓慢闲逛，随机做出舔毛、打盹、追毛线球等行为；左键点击可以互动和拖动，双击可以让它打盹，右键打开功能菜单。

## 快速体验（需要 Python 3.10 或更新版本）
1. 安装 Python（安装时勾选 Add Python to PATH）。
2. 双击 `run_pet.bat`，第一次运行会自动安装依赖。
3. 猫咪会出现在桌面上。

## 打包成可分享的 EXE
1. 在 Windows 电脑上安装 Python 3.10+。
2. 双击 `build_windows.bat`。
3. 等待打包完成，成品在 `dist\CreamCatPet.exe`。
4. 将该 EXE 分享给其他 Windows 10/11 电脑即可试用。第一次运行可能被 Windows SmartScreen 提示，因为软件没有代码签章；这不代表已通过安全认证。只从你信任的来源分享。

## 操作方式
- 左键点击猫咪：触发随机互动。
- 按住左键拖动：移动猫咪位置。
- 双击猫咪：让它打盹。
- 右键：打开菜单，可玩毛线球、梳理毛毛、睡觉、切换置顶、显示/隐藏毛线球或退出。
- 猫咪图片位于 `assets/cat.png`，可以替换成自己的透明 PNG。

## 说明
这是第一版原型。猫咪“舔毛/睡觉”等动作目前用文字气泡和状态模拟，真正的舔毛姿势、走路循环等需要额外的动作帧或 GIF/精灵图。窗口透明效果取决于 Windows 图形环境。
